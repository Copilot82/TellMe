# Picture in Picture: итог стабилизации

Рабочий журнал physical-device прогонов заменён на очищенный технический разбор. Это исключает из
публичного репозитория environment-specific identifiers, локальные artifact paths и временные
диагностические команды.

Актуальный документ:
[docs/case-studies/pip-stabilization.md](../docs/case-studies/pip-stabilization.md).

Исходные `.xcresult`, screenshots и JSONL diagnostics хранятся вне Git и используются как release
evidence только в приватном operational контуре.
